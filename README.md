### Ключевой кейс

**Миграция промышленного приложения для рудников** ноябрь 2025 — август 2026.

Приложение переносили с legacy-монолита C#/WPF на микросервисы. Требования собрала из кода, договоров и устных запросов и превратила постановку «перенести как есть» в переосмысление продукта. Черновики документов готовила с помощью ИИ — это ускорило работу примерно на 30%.

### Проекты

**Приложение для заказа + табло** — курсовой проект OTUS «Системный аналитик. Advanced». Документация системы заказа для ресторана быстрого обслуживания: киоск самообслуживания, табло готовности и панель персонала. Внутри — бизнес- и функциональные требования, информационная модель, схемы C4 в PlantUML, спецификация OpenAPI 3.0.3, задачи, тест-кейсы и чек-лист приёмки.

Документация: [сайт](https://coffeeprograms.github.io/sa-coursework-restaurant/)

**Таверна Helios. Организация обедов** — учебный командный проект курса OTUS «C# ASP.NET Core разработчик» (январь–июнь 2025; документацию переработала в 2026). Веб-сервис бронирования обедов: сотрудники выбирают блюда из меню на день, время и место за столом, менеджер ведёт меню и схему зала и передаёт отчёт ресторану. В команде была системным аналитиком и разработчиком: требования и пользовательские истории с критериями приёмки, модели и диаграммы C4, контракт API, ревизия кода на соответствие требованиям.
